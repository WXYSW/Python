## 第一阶段：建立直觉 (第1-2周)

这个阶段的本质，是跨越对编程的恐惧。你不需要成为软件工程师，你只需要成为一个“指令发送员”。

**1. 最小化 Python 语法 (2天)** 放弃那些厚重的 Python 教程，你只需要搞懂四个核心概念：

- **变量与数据类型**：怎么存一段文字（String），怎么存一组数据（List/Dict）。
    
- **控制流**：`if-else`（条件判断）和 `for/while`（循环）。
    
- **函数**：怎么把一段重复的代码打包成一个工具（`def`）。
    
- **包管理**：学会用 `pip install` 下载别人写好的代码库。
    

**2. 搞懂 API 与 JSON (3天)** 这是现代互联网流通的血液。

- 理解 HTTP 请求：明白什么是 GET（获取信息）和 POST（提交信息）。
    
- 解析 JSON：大模型和你的代码沟通的唯一语言。它本质上就是一个键值对（Key-Value），像查字典一样。
    

**3. 第一次唤醒大模型 (2天)**

- 注册 DeepSeek 开发者账号，获取一串名为 `API Key` 的密钥（这是你调用大模型的通行证）。
    
- 使用 Python 的 `requests` 库或官方 SDK，发送一段提示词（Prompt），并把模型返回的回复（Completion）打印在屏幕上。
    
- **MVP 目标**：写一个无限循环的 `while True` 命令行，实现你问一句，AI 答一句的控制台聊天机器人。
    

## 第二阶段：组装外脑 RAG (第3-5周)

大模型是没有记忆的。这个阶段的本质，是教你如何给它外挂一块“无限容量的硬盘”。

**1. 文本处理与切片 (Chunking) (3天)**

- 学会用 Python 读取本地的 `.txt` 或 `.pdf` 文件。
    
- 写代码把几万字的长文，切成每段 500 字的“文本块”。（思考：切得太短会失去上下文，切得太长会超出大模型处理上限，这就是工程师要权衡的边界）。
    

**2. 向量化 (Embedding) 与数学直觉 (4天)** 计算机看不懂文字，只能看懂数字。

- 调用 Embedding 模型的 API，把你切好的文本块，变成一串几千维的浮点数数组（向量）。
    
- 建立直觉：语义越相近的句子，它们在多维空间中的“距离”就越近。
    

**3. 向量数据库查询 (ChromaDB) (3天)**

- 安装轻量级的 ChromaDB，把你生成的“向量”和“原始文本”存进去。
    
- 当你提出一个问题时，把问题也变成向量，然后在数据库里搜索“距离最近”的前 3 个文本块。
    

**4. 组装 Prompt (4天)**

- **MVP 目标**：把搜出来的 3 个文本块，连同你的问题，通过代码拼接成一段话：“请根据以下参考资料回答问题：[参考资料]。我的问题是：[问题]。” 然后把这段话发给大模型。
    
- 恭喜，你已经手写了一个企业级的本地知识库。
    

## 第三阶段：智能体编排 (第6-10周)

单体大模型只是个“打字员”，Agent（智能体）才是能干活的“数字员工”。这个阶段的本质是理解流程控制。

**1. 大模型工具调用 (Function Calling) (1周)** 大模型默认只能输出文字。你要学的是如何强迫它输出特定格式的指令。

- 写一个查询本地天气的 Python 函数。
    
- 在给大模型的 API 请求中，告诉它“你有这个天气函数可用”。
    
- 当大模型判断需要查天气时，它会输出一段特定的 JSON。你的代码捕获这段 JSON，在本地运行天气函数，再把结果喂回给大模型。
    
- 这是 Agent 能够“感知并影响物理世界”的第一步。
    

**2. 状态机与图结构认知 (LangGraph) (2周)**

- 忘掉传统的线性代码逻辑。把工作流想象成一张地图（Graph）。
    
- 学习定义“节点（Node）”：每一个节点就是一个独立的 Agent，负责干特定的活。
    
- 学习定义“边（Edge）”：写条件判断代码，决定数据什么时候从 Agent A 流向 Agent B。
    
- 学习管理“状态（State）”：在所有 Agent 之间传递一个公共的黑板（Memory），大家都在上面读写信息。
    

**3. 多智能体协同博弈 (2周)**

- **MVP 目标**：构建一个“爆款文案流水线”。
    
- Agent 1：负责根据你的主题，生成 3 个标题。
    
- Agent 2（评估者）：负责根据“吸引眼球”的标准，给这 3 个标题打分。如果最高分低于 80 分，打回给 Agent 1 重写（形成循环）；如果高于 80 分，输出给用户。
    
不要去等什么“完全准备好”的时刻，工程世界里没有这种时刻。只要你跨越了那个“最小能力阈值”，你就该把自己扔进真实的市场里去摸爬滚打。

我们用第一性原理，把“找实习”和“拿高薪”这两个黑盒拆解开。

## 实习及格线：成为一个合格的“API 拼接匠与排雷兵”

当你能独立完成以下三件事时，你就不再是零基础的小白，而是可以立刻开始投递简历的准工程师：

**1. 拥有工程洁癖与自我排雷能力（核心生存技能）**

- **代码卫生**：绝不会把 API Key 直接写死在代码里提交到 GitHub（学会使用 `.env` 环境变量）。
    
- **版本控制**：会用基础的 Git 命令（`clone`, `commit`, `push`, `pull`，甚至遇到冲突知道怎么放弃本地修改）。
    
- **独立 Debug**：遇到终端里红通通的一大片报错，第一反应不是去问前辈，而是把报错信息喂给大模型，或者去 Stack Overflow 寻找答案。实习生最核心的能力是“不给团队添麻烦”。
    

**2. 徒手捏出一个完整的 MVP（闭环能力）**

- 你不需要懂底层的并行计算，但你必须能端到端跑通一个应用。
    
- **标准**：你能用 Streamlit（前端）+ 某家大模型的 API（大脑）+ ChromaDB（外脑记忆），自己写代码，在本地跑起一个属于你自己的 RAG 知识库问答机器人。
    

**3. 具备“结构化 Prompt”的工程思维**

- 不再像普通用户那样用大白话和大模型聊天，而是能写出带有系统设定（System Prompt）、输入输出约束（JSON 格式要求）、Few-Shot（少量示例）的工业级提示词。
    
- 你能控制大模型的“幻觉”，让它的输出具有可预期性。
    

**企业家的行动建议：** 不要海投简历。花一个周末，找一家你喜欢的创业公司，研究他们的业务痛点。用上面学到的技术栈，花极低的成本给他们做一个“内部提效 AI 小工具”（比如：自动抓取竞品新闻并生成日报的 Agent），把代码运行录成 3 分钟的视频，连同简历直接发给他们的创始人。这叫降维打击。

## 职业晋升路线：从“解决问题”到“定义问题”

在这个 AI 一天迭代一个版本的时代，晋升的核心逻辑只有一条：**不断扩大你应对“不确定性”和处理“模糊性”的杠杆率。**

### L1：AI 助理工程师 (Intern / Junior) —— 拆解者

- **日常状态**：接到明确的需求（“把这个长文本总结成 3 个要点并存入数据库”），写出稳定的代码。
    
- **核心竞争力**：手速快，API 熟练，能快速搞定数据清洗、接口对接等脏活累活。
    
- **技术跨越**：从面向过程编程，转向面向对象与模块化编程，学习写出别人能看懂、易于维护的代码。
    

### L2：多智能体架构师 (Senior) —— 缝合者与系统思考者

- **日常状态**：面对半模糊的需求（“我们的客服机器人总是乱回答，退单率很高”），设计系统架构。
    
- **核心竞争力**：概率思维与架构能力。你开始深刻理解大模型的局限性。你不再迷信单次 Prompt 的魔法，而是引入工程手段（如 LangGraph 状态机、多 Agent 博弈、Ragas 自动化评估流、意图路由）来强行拉高系统的下限。
    
- **技术跨越**：掌握复杂系统设计，关注并发延迟（Latency）、Token 成本控制优化、并发安全。
    

### L3：AI 产品工程师 / 业务 Leader (Staff / Principal) —— 跨界连接者

- **日常状态**：面对完全模糊的商业目标，决定“我们不该做什么”。
    
- **核心竞争力**：技术人文主义。这是最值钱的阶段。你不仅懂技术边界，更懂人性幽暗和商业逻辑。你开始用科学家的眼光审视前沿论文，用企业家的直觉判断哪些新技术能真正转化为用户的“爽点”。你不再只是写代码，你在用 AI 重新设计业务的 S-OP（标准作业程序）。
    
- **技术跨越**：脱离具体框架的束缚，能够在模型微调（Fine-tuning）、知识图谱和复杂 Agent 架构之间做战略取舍。
